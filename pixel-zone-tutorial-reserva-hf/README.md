# Pixel Zone · Como reservar em pixelzone.pt (HyperFrames)

Tutorial de 30,5 s, 1080x1920. Arquivo final: `pixel-zone-tutorial-reserva-hf.mp4`.

- Capturas reais do site: `node tools/capture.cjs assets/shots` (Playwright, iPhone 13). Nada é enviado no site.
- Cenas: `python3 tools/gen.py` (tempos da narração em `assets/words.json`, toques em `assets/shots/meta.json`).
- Narração: edge-tts (pt-BR-AntonioNeural), conferida com Whisper. Efeitos: Earshot. Música: Openverse/Freesound,
  "Cyberpunk Beat" por Disquantic, CC0 (`assets/music/CREDITS.txt`). Fonte: Barlow Condensed (OFL).
- Ver `SPEC.md` e `REVIEW.md`.
